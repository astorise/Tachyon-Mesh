# Configuration Exposure Audit

This document tracks `IntegrityConfig` fields that are intentionally edited
through the sealed manifest path. The live schema is available from
`GET /admin/schema/manifest`; Tachyon Studio uses `get_manifest_config` and
`apply_manifest_config` for the operator fields listed below.

## Exposed In Tachyon Studio

| Field | Surface |
|---|---|
| `enrollment.mode`, `enrollment.oidc_issuer`, `enrollment.oidc_audience`, `enrollment.auto_approve_tags` | Nodes panel, Enrollment policy form |
| `tee_backend` | Routing panel, Manifest routing controls |
| `routes[].requires_tee` | Routing route table TEE toggle |
| `layer4.tcp[]`, `layer4.udp[]` | Routing panel, TCP/UDP binding text areas |
| `routes[].volumes[].backup_schedule` | Expanded route Volumes panel |
| `routes[].volumes[].consistency` | Expanded route Volumes panel |
| `routes[].volumes[].encrypted`, `ttl_seconds`, `idle_timeout`, `eviction_policy`, `type` | Expanded route Volumes panel |
| `require_scopes` | Routing panel, Manifest routing controls |
| `trusted_signers` | Identity panel, Trusted manifest signers form |
| `telemetry_sample_rate`, `instance_pool_max_memory_bytes`, `cloud_sync_endpoint`, `batch_targets` | Routing panel, Manifest routing controls |

## Manifest Only

The following fields remain manifest-only because they are generated by bundle
apply or are low-level runtime inventory rather than operator policy:

| Field | Reason |
|---|---|
| `asset_versions` | Maintained by bundle apply for dependency conflict detection. |
| `kv_caches[].tenant_isolation` and low-level cache limits | AI panel creates cache declarations, but detailed cache tuning stays in the manifest schema until runtime telemetry has a stable editing workflow. |
| `resources` method/version constraints | Resource editing is still handled by the resource and supply-chain surfaces; advanced constraints are documented by the schema. |

When adding a new `IntegrityConfig` field, either add a Tachyon Studio or MCP
editing surface, or add it to this manifest-only table with a reason.
